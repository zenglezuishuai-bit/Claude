## 俯视图

12 号图由 Esri World Imagery Web Mercator zoom 18 瓦片拼接。范围 x=236630…236635、y=160858…160861。中心纬度处约 0.4717 m/px，100 m 比例尺四舍五入为 212 px。适合校准总体平面布局；屋顶因摄影视角可能有位移，不能当作测绘图。影像拍摄日期未核实。
